## 重要决策
1. **语义地图模块化** — 将单体 `semantic_map.py` 拆分为 `map/` 子包，按职责分离为 store、summarizer、diff、publisher，提高可维护性和可测试性
2. **Revision-aware continuity** — 引入确定性 revision 版本号，每次地图变更会生成结构化 delta，而非每次 LLM 轮次都强制生成自然语言摘要，降低 token 开销
3. **地图状态注入 Context** — 通过 CoordinatorPinnedState 新增 map_revision/map_delta/map_summary 字段，在每次 LLM 轮次前自动注入，不再是独立的 debug 工具
