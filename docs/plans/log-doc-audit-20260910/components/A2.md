## 三、Gap 清单（按严重度）

### 🔴 G1（conflict，最高优先）TaskLogger 文件名 fallback 文档错误
- 文档：logging_map.md:35 "文件名 = safe_name（friendly_name）或 task_id"、:260 "否则 `<task_id>.ndjson`（:53/:94–103）"；AGENTS.md:155 "TaskLogger writes `<safe_name|task_id>.ndjson`"
- 实际：task_logger.py:60-77 `init_task` 无 friendly_name 时 `safe_name = datetime.now().strftime("%Y%m%d_%H%M%S")`（:66-67）；log_event 经 get_log_path 命中 `_name_map` 注册的 safe_name → 文件名为时间戳
