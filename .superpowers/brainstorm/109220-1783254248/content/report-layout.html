标签页说明

  • Timeline：按步骤展示每个智能体的动作、成功/失败、位置/背包，以及全局观察摘要。
  • Coordinator：展示协调器下发的任务、query_task_events 时间点、子任务状态。
  • Token Usage：每步 token 柱状图 + 累计折线图，按 Agent/Coordinator 拆分。
  • Semantic Map：从 semantic_map.jsonl 聚合的火、水库、人质、仓库对象表，含位置、强度变化、冲突标记。
  • LLM Trace：完整保留 worker 的 llm_request / llm_response / tool_result，默认折叠，可展开。

关键交互

  • 顶部标签切换不同视图。
  • Timeline 可展开单步的完整 observation。
  • Token 图表支持 hover 查看数值。
  • LLM Trace 按 task/agent 分组，点击展开完整 prompt/response。
