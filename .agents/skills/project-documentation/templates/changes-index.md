# Changes

This directory contains active or recently completed change documents. These
records describe intent and evidence; they do not override current architecture
until implementation is verified and the affected canonical docs are updated.

## Status rules

- `draft`: intent is being shaped; not approved for implementation.
- `active`: implementation or verification is in progress.
- `verified`: required checks passed and durable docs were reconciled.
- `abandoned`: intentionally stopped; preserve the reason.
